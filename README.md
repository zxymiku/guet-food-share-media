# 桂电美食分享 · 媒体

桂林电子科技大学美食分享项目的公开媒体仓库。

图片与视频以 AES-256-GCM 分块加密后，存入本仓库的 GitHub Releases 附件（.gefm）。这里不提交原始照片或视频到 Git 历史，也不保存解密密钥。待审内容由应用限制访问，审核公开后在应用观看。

主项目：https://github.com/zxymiku/guet-food-share

Web：https://github.com/zxymiku/guet-food-share-web

媒体仓库保持公开，不承诺无限存储、无限流量或永久可用。请勿删除仍在使用的 Release 附件；密钥丢失将无法恢复媒体内容。
